# MODE=2 直接闭环启动修复试验

本文件夹是修复版。`../mode2_direct_start` 和 `../flux_observer` 保留不动；STM32 固件没有修改。这里修复的是 Simulink 控制/观测接口和电压补偿，不是给显示波形加平滑。

## 使用

MATLAB 当前目录切到本文件所在目录：

```matlab
start_mode2_repair('open')    % 打开修复后的模型，点击 Run
start_mode2_repair('reload')  % 关闭内存中的旧模型，重新打开磁盘修复版
start_mode2_repair('run')     % 按参数重建并导出波形
start_mode2_repair('verify')  % 重建、核对连接、测试初始位置和死区偏差
```

主模型只有一个：`model/G474_Mode2_Direct_Start_Repair.slx`。它与原模型名称不同，可以同时打开。模型内嵌算法和参数，不需要 Simscape；构建时从保留的观测器/PI 模型读取模块并复制，解除库链接，不保存原模型。

工况：12 V；0、0.8、1.6 s 分别给定 200、400、1000 rpm；初始速度和电流为零，物理初始电角度默认每次普通仿真在 [0°,360°) 均匀随机生成；仿真 4 s。观测器角度和磁链仍从零初始化，不使用这个物理角度。仍为 mode=2 直接闭环，没有预定位、VF、已知角度磁链预置或真实角度/速度反馈。最新启动优化会先保持零参考 150 ms，让观测器内部状态自然建立，再释放速度参考；这段期间没有定位电流和转子运动，已加入数值检查。

模型 InitFcn 在每次普通仿真初始化时抽取角度（不要启用快速重启），并在 MATLAB 命令窗口打印本次角度；模型工作区 `q.initial_theta_e` 保存弧度值。`run` 导出的 MAT 和 simulation_report.txt 记录实际使用的角度。随机工况可能启动失败，这是当前控制策略的实际限制。`verify` 仍用固定 30° 做标称回归，再执行固定角度扫描，结束恢复随机启动默认设置。

复现指定角度可以运行 ` [~,q]=mode2_params(); q.initial_theta_e=90*pi/180; result=run_mode2(q); `，显式传入条件会关闭随机抽取。若直接在模型工作区修改，设置 `q.random_initial_angle=false` 和 `q.initial_theta_e` 即可；初始状态由回调同步更新。随机角度与原基线不同时，不生成新的启动优化前后对比图，已有对比文件仍为历史固定角度结果。

## 修了哪些地方

1. **Iq 给定符号。** 在本模型的标准绕组相序/正向电流约定下，改为正速度误差请求正转矩，`speed_iq_sign=+1`。实机符号仍应与接线和采样极性对应。
2. **观测器电压统一。** 根据上一拍已知 PWM 指令重建原始 SVPWM 扇区、CCR 截断/限幅和 `CCR/4000` 对应的相电压，再根据上一拍采样电流估计死区电压。观测器不再直接把 `command×Vbus` 当成实际施加电压。输入单位现在是 V，不能再额外乘母线电压或重复添加死区补偿。
3. **电流采样同步。** 观测器使用当前采样计算的 Clarke 电流，而不是上一拍 Clarke 结果；上一拍电流保留用于重建该拍已施加的 PWM 电压。
4. **平滑给定。** 在原 1000 rpm/s 斜坡前增加两级 2 Hz 一阶滤波。这会改变电机实际收到的速度参考，目标、平滑参考、实际和估算转速都分别显示；没有剪掉启动数据。
5. **逆变器死区前馈。** 在实际 PWM 指令端，根据采样电流极性补偿估计的 0.3 V 死区损失。0.5 s 后用 0.5 s 逐渐投入，同时用估算转速 80～160 rpm 做投入门控，避免零速未锁定时直接加上完整补偿。这项补偿改变实际电压，不处理转矩显示。观测器仍独立重建补偿后的 PWM 对应的实际电压。
6. **小负载定义。** 默认采用阻碍转动的负载 `Tload=0.005*tanh(wm/1) N·m`。原固定方向的负载转矩会在零速时主动把电机拖反；它仍可通过 `load_speed_scale_rad_s=0` 选择，适合外部恒定反转矩场景。
7. **启动初始化等待。** `reference_start_delay_s=0.15`：在 mode=2 内，先让观测器在零参考、零实际电流下运行 150 ms，再启动既有参考滤波/斜坡。没有改 PLL、速度滤波或 PI 系数，也没有在估算转速输出上增加滤波。代价是电机开始加速晚 150 ms；完整时间轴和按参考释放时刻对齐的误差都列在对比图中。将该参数设为 `0` 可恢复立即释放参考的旧行为。

**PI 算法、Kp、Ki 均保留源码：**速度环 0.01 / 0.0001，电流环 0.01 / 0.00001；Ki 为每次调用的离散系数，不能再乘 Ts。积分冻结仍由上一拍未限幅 v1 决定，OutF 仍为 `0.9*old+0.1*Out`。速度 PI 输出限幅恢复为源码的 ±12 A 给定限幅；临时测试的 ±2 A 给定限幅会在部分工况下使起动失败，已撤回。±12 A 是给定限制，不表示实际电流达到 12 A。

- `02_PWM_Voltage_and_Current_Sampling`：PWM/CCR 电压重建、当前 Clarke、电压/电流帧分别展开。
- `03_Hybrid_Flux_Observer`：电流/电压磁链模型、反馈 PI、磁链积分、PLL 和速度滤波分别展开。
- `05_Speed_Ramp_and_PI`：`01_Observer_Warmup_and_Command_Shaping`、`02_Speed_Slew_Limiter`、`03_Speed_PI_Output_and_Polarity`。第一层中可查看初始化计时、参考释放开关和两级滤波。
- `06_Id_Iq_PI_and_Voltage_Circle`：d 轴 PI、剩余电压圆、q 轴 PI 分开，PI 内部是原生离散运算模块。
- `07_InversePark_SVPWM_Inverter`：反 Park、门控死区电压前馈、SVPWM/平均桥电压。
- `08_PMSM_Electrical_Mechanical_Plant`：dq 电气、转矩/机械方程和物理测量；角度和速度真值只供物理模型自身、绘图与检查使用。

## 转矩尖峰的解释

本电机模型 Ld=Lq，`Te=1.5×7×0.00752×Iq_actual=0.07896×Iq_actual N·m`。应使用物理转子坐标下的 Iq，而不是直接把未锁定时控制器坐标中的 Iq 当成实际转矩电流。

临时 2 A 限幅试验中，电机未锁定，实际速度约 -17 rpm；转矩约 -0.0089～+0.0064 N·m，与所反馈的截图一致。它是失败启动工况，不能当成正常稳态。电流过零处硬切换的死区电压、角度误差和电流环响应共同产生周期尖峰。这里是平均逆变器模型，不能将这些尖峰笼统解释为 PWM 开关纹波。

`torque_diagnosis.png` 同时画出原始转矩、实际 Iq、角度误差和电压重建，便于区分转矩电流、角度和电压的问题。转矩记录、示波器和峰峰值计算均没有加显示滤波。

## 参数与结果

参数集中在 `scripts/mode2_params.m`。电气参数仍为 Rs=0.875 Ω，Ld=Lq=0.2 mH，永磁磁链 0.00752 Wb，7 极对，20 kHz；PLL/磁链补偿 PI 沿用源码参数。

**仿真假设单独列出：**J=2e-5 kg·m²，B=1e-5 N·m·s/rad；负载幅值 0.005 N·m；实际死区、观测器死区估计、逆变器前馈估计分别为 0.3 V，可独立修改。模型没有 ADC 噪声、开关纹波或硬件保护。标称补偿效果依赖估计准确度，验证报告另列实际死区 ±20% 的情况。

- `results/mode2_startup.png`：启动与三段切速。
- `results/startup_optimization.png`：启动优化前后，分别显示实际速度、原始估算速度、按参考释放时刻对齐的估算误差和完整三段切速。
- `results/startup_optimization_report.txt`：等待时间、实际/估算峰值、误差、收敛时间、电流峰值的前后对照；旧模型/数据保存在 `work/startup_before_model.slx`、`work/startup_before.mat`。
- `results/torque_diagnosis.png`：原始稳态转矩与相关量。
- `results/torque_before_after.png`：临时 2 A 失败工况与修复标称工况；两个试验条件明确分开标注。
- `results/simulation_report.txt`：三段实际/估算转速、启动超调、反摆、未滤波转矩均值/峰峰值。
- `results/verification_report.txt`：原生块与独立 MATLAB 参考核对、标称验收、初始位置/死区偏差检查。
- `results/initial_angle_sweep.csv`：0°、30°、90°、180°、270° 起动结果。
- `results/model_diagram.png`、`scopes_11.png`：模型与示波器布局。
- `results/mode2_results.mat`：完整 34 路采样记录；14 列为物理转矩，12 列为实际 rpm，3 列为估算 rpm，13 列为仅用于分析的真实电角度。
- `work/`：缓存、探索试验与旧复制文件；不作为交付模型。

**适用范围：**固定标称初始角度 30° 的通过不等于任意位置可靠起动；当前默认随机角度用于暴露这一限制。本次测试中 90°、180° 起动失败；实际死区为 0.24 V、估计仍为 0.3 V 时也失败。完整数值保留在验证报告中，没有用真实转子角度初始化观测器来制造成功。如果要求全位置可靠零速无感起动，还需要另行设计位置获取/起动策略，而不能只凭这组仿真调 PI。
